# Research

Version 3 extends the World Cup 2026 Football Simulation Framework into a computational football research platform.

The simulation engine, Player Intelligence system, Competition Framework, and Football Model provide the infrastructure for answering reproducible research questions about football.

Research is organized into thematic programs, each consisting of multiple experiments, reports, and supporting outputs.

# Research Philosophy

Each experiment should:

1. Ask one clear research question.
2. Change one independent variable.
3. Hold all other variables constant.
4. Produce reproducible outputs.
5. Leave behind structured artifacts:
   - Report
   - CSV results
   - Metadata
