Version 3 Research Methodology
Purpose

Version 3 marks the transition from software development toward computational football research.

Versions 1 and 2 established the computational infrastructure required to simulate football competitions, represent player and team strength, and analyze tournament outcomes.

Version 3 uses that infrastructure to investigate football itself through controlled computational experiments.

The objective is no longer to ask:

Can the framework support this feature?

Instead, the objective becomes:

What can computation reveal about football?

Research Philosophy

Every experiment should satisfy five principles.

Principle 1

One football question.

Every experiment should answer one clearly stated question.

Not five.

Not twenty.

One.

Principle 2

One independent variable.

Only one thing changes.

Everything else remains fixed.

Principle 3

Reusable methodology.

Every experiment follows the same structure.

Principle 4

Evidence before conclusions.

Observers produce measurements.

Metrics summarize observations.

Interpretation follows evidence.

Principle 5

Reproducibility.

Every experiment should be rerunnable using the same:

framework version,
player repository,
match engine,
random seed policy,
simulation count.

Fixed Variables

These remain identical throughout an experiment.

Examples:

Player Intelligence repository
Match engine
Goal model
Simulation count
Random seed policy
Observer set
Independent Variable

Exactly one component changes.

Examples:

competition format
tournament size
seeding policy
lineup uncertainty
Dependent Variables

The quantities being measured.

Initially:

strongest-team championship rate
champion strength
upset frequency
champion variance
Version 3 Metric Philosophy

Metrics should be:

interpretable,
reusable,
comparable,
competition-independent.

New metrics should be added only when they answer a new football question.

Reporting Philosophy

Every experiment concludes with:

What surprised us?

Rather than merely listing limitations, experiments should explicitly identify unexpected findings generated by simulation.

This encourages discovery rather than confirmation.

Version 3 Identity

Version 3 treats the computational football framework as a scientific instrument.

The framework itself is no longer the primary deliverable.

The primary deliverable becomes evidence about football generated through computational experiments.
