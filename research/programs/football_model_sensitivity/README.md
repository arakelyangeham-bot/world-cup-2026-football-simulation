# Football Model Sensitivity Program

## Mission

Determine which football-model components materially influence computational football conclusions.

Rather than searching for a "best" football model, the goal is to understand how sensitive research findings are to different modeling decisions.

# Guiding Principle

Each experiment modifies one football-model component while holding all remaining variables constant.
