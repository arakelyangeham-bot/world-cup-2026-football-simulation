# Research Prototype 001 — Design Note

## Candidate Theme

Scoreline Realization

## Core Question

Can one empirically motivated adjustment improve generated scoreline realism without destabilizing outcome calibration or tournament behavior?

## Candidate Hypotheses

1. Competitive resolution adjustment
2. Draw / one-goal balance adjustment
3. Low-score equilibrium adjustment

## Selection Criteria

Prototype 001 should choose the hypothesis that is:

- directly connected to the Football Gap Report,
- supported by Studies 003–007,
- small enough to implement behind the research seam,
- benchmarkable against production,
- reversible if it fails.

## Initial Recommendation

Start with the smallest possible scoreline-realization adjustment targeting the draw / one-goal balance.

No production code changes.
